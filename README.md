# هندسة — PWA جاهز للرفع

تطبيق ويب يتثبت على الموبايل والكمبيوتر ويشتغل **أوفلاين**.

## الملفات
- `index.html` — التطبيق كله (ملف واحد).
- `manifest.webmanifest` — بيانات التثبيت (الاسم، الألوان، الأيقونات).
- `sw.js` — الـ Service Worker: بيحفظ التطبيق للعمل بدون إنترنت.
- `icons/` — الأيقونات (192 و512 و maskable و iOS).

## الرفع (اختار واحد)

### 1) GitHub Pages (مجاني)
1. اعمل Repository جديد على GitHub (مثلًا `handasa`).
2. ارفع **محتوى** المجلد (مش المجلد نفسه) في الـ root.
3. من Settings ← Pages: اختار Branch `main` والفولدر `/ (root)` ثم Save.
4. بعد دقيقة الرابط هيبقى: `https://USERNAME.github.io/handasa/`

### 2) Netlify Drop (أسرع)
1. افتح https://app.netlify.com/drop
2. اسحب المجلد كله على الصفحة. هتاخد رابط فورًا.

> لازم يتفتح من رابط **https** عشان التثبيت والأوفلاين يشتغلوا (مش من ملف على الجهاز).

## التثبيت
- **أندرويد (Chrome):** افتح الرابط ← زر "📲 تثبيت" في Settings، أو قائمة ⋮ ← Install app.
- **آيفون (Safari):** زر المشاركة ← Add to Home Screen.
- **كمبيوتر (Chrome/Edge):** أيقونة التثبيت في شريط العنوان.

## تحديث التطبيق
بعد أي تعديل في `index.html` غيّر الرقم في `sw.js`:
```js
const VERSION='handasa-v2';
```
وارفع الملفات تاني. المستخدمين هيستلموا النسخة الجديدة عند الفتح التالي.

## ملاحظات قبل النشر
- التمارين من ورق مادة الرسم الهندسي (جامعة الجلالة). خد موافقة الدكاترة قبل النشر العام، ووضّح إن التطبيق مش رسمي من الجامعة.
- أسابيع 1–4 موجودة (28 رسمة). الأسبوع 4 فيه خيار الزاوية الأولى/الثالثة من Settings.
- التقدم والإعدادات محفوظين على نفس الجهاز بس (localStorage).
